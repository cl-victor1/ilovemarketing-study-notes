- クラウドファンディング、ゲーム化されたチャレンジ、オンデマンドのフリーランス プラットフォーム、データ マイニング コンテストなどのツールにより、個人はかつて大手企業しか利用できなかった世界的な人材やリソースにアクセスできるようになります。
